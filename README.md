# Wellbeing365 Proposal Site

Static site built from:

- `Work/WhiteHorse AI/Proposals/Robbie Hunt - Wellbeing365/robbie-hunt-wellbeing365-premium-proposal.html`

## Files

- `index.html`: client-facing proposal page.
- `.nojekyll`: tells GitHub Pages to serve the folder as plain static files.
- `wellbeing365-proposal-site.zip`: upload-ready copy of `index.html` and `.nojekyll`.

## Publish With GitHub Pages

1. Create a new public GitHub repository, for example `wellbeing365-proposal`.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Open repository Settings.
4. Go to Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Choose branch `main` and folder `/root`.
7. Save.
8. GitHub will publish a link like `https://YOUR_USERNAME.github.io/wellbeing365-proposal/`.

Do not publish private client notes, API keys, bank details, or internal source files. This folder only contains the static proposal page and GitHub Pages helper file.
